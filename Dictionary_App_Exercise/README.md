# Dictionary App (SQLite + Kotlin)

A simple dictionary app using SQLiteOpenHelper and Jetpack Compose.

## Features
- Exact match lookup with definition output.
- Substring search for suggestions when no exact match exists.
- Pre-populated sample words on first run.

## Run
- Open the project in Android Studio and run the `app` configuration.
