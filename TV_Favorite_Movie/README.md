# TV Favorite Movie (Android TV)

Leanback-based Android TV app that shows a favorites list and a simple details screen.

## Quick start

1. Open the project in Android Studio and let Gradle sync.
2. Run on an Android TV device or emulator.

## Optional CLI build

```powershell
.\gradlew :app:assembleDebug
```

## Notes

- Movie data is sample-only in `MovieList.kt`.
- UI colors are defined in `app/src/main/res/values/colors.xml`.
